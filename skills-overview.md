# OpenCode Skills Overview

**16 skills** organized by functional domain.

## Development Tools

| Skill                | Purpose                                                                   |
| -------------------- | ------------------------------------------------------------------------- |
| **skill-creator**    | Create, edit, and optimize AgentSkills                                    |
| **skill-manager**    | Scan, classify, analyze, and manage AgentSkills collections               |
| **code-reviewer**    | Code review focused on security, performance, and best practices          |
| **project-signpost** | Generate hierarchical README navigation files for AI-assisted development |

## Academic Research

| Skill                            | Purpose                                                                                         |
| -------------------------------- | ----------------------------------------------------------------------------------------------- |
| **academic-researcher**          | Academic research assistant for literature reviews, paper analysis, and equation derivation     |
| **literature-review**            | Systematic literature review with multi-database search (PubMed, arXiv, etc.)                   |
| **peer-review**                  | Peer review toolkit for evaluating methodology, statistics, and reproducibility                 |
| **write-paper**                  | Generate LaTeX academic papers from research project files                                      |
| **deep-research**                | Deep research with multi-source synthesis and citations                                         |
| **arxiv-search**                 | Search arXiv for preprints and academic papers                                                  |
| **read-arxiv-paper**             | Read and analyze arXiv paper source files                                                       |
| **research-grants**              | Write research grant proposals (NSF, NIH, DOE, DARPA)                                           |
| **scientific-critical-thinking** | Evaluate scientific claims, bias detection, and evidence quality assessment                     |
| **scientific-brainstorming**     | Research ideation partner for generating hypotheses and exploring interdisciplinary connections |
| **response-to-referee**          | Generate professional point-by-point responses to peer review comments                          |

## General Utilities

| Skill             | Purpose                                                                       |
| ----------------- | ----------------------------------------------------------------------------- |
| **brainstorming** | Turn ideas into designs before implementation (required before creative work) |

## Usage Notes

- Skills auto-trigger via their `description` field—no manual invocation needed
- Academic skills can be chained: `arxiv-search` → `read-arxiv-paper` → `literature-review` → `write-paper`
- Always use `brainstorming` before starting any development work
