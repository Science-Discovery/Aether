## 总体概览

这 50 个 commit（2026-04-28 ~ 2026-05-02）涵盖了三大核心功能引入：

- **Cron 定时任务系统**（#474）— 支持 cron/interval/once 调度的 agent 自动化
- **Memory Profile 持久记忆系统**（#485）— 类型化记忆存储、LLM 反思、自动召回
- **Steer 操控按钮**（#539）—AI 生成中途注入引导

以及**阅读模式全面重构**（#554）、消息折叠、模型可见性统一、项目图标覆盖、base path 运行时支持、空闲超时配置等大量 UI/UX 改进，同时修复了 SSE 僵尸连接、PDF 查看器、Windows 路径显示等关键 bug。

主要 Maintainer：**Dongshan Jian**（合入 29 次）和 **yqmaphy**（合入 14 次，PR 作者 23 次）。
