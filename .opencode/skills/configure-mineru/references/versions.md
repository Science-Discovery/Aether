- uv: `0.12.1`
- Python: `3.12.10`
- MinerU: `3.4.4`
- Model source: `modelscope`
- Backend: CPU-compatible `pipeline`

The uv archive must come from `https://releases.astral.sh/github/uv/releases/download/0.12.1/uv-x86_64-pc-windows-msvc.zip` and match SHA256 `8fcb0cb46e1229065e344758980924e569bef5882ef45f46fada8fb24e06b74a`.

Use only official sources when explaining compatibility or resolving the optional latest channel:

- MinerU quick start: `https://opendatalab.github.io/MinerU/quick_start/`
- MinerU usage: `https://github.com/opendatalab/MinerU/blob/master/docs/en/usage/quick_usage.md`
- MinerU package index: `https://pypi.org/project/mineru/`

The latest channel changes the resolved MinerU version only after explicit user choice. It does not enable automatic upgrades or GPU installation.
